# 차트 CNN 연구 — 코드와 실행 순서

계획 원문: [[연구계획_필독논문_선행판정]] · 기획안: [[[26-2 페이퍼스 2주차] A조_차트 딥러닝 알파의 결정 요인과 실현 가능성]]

## 실행 순서

0. **(사람)** KRX 정보데이터시스템(data.krx.co.kr) 계정을 자기 터미널에서 `setx KRX_ID 아이디`, `setx KRX_PW 비밀번호`로 등록한다. 대화창이나 볼트에는 남기지 않는다.
1. `py -3 code/00_access_test.py` — 계획 3단계 데이터 접근 테스트(⛳ pykrx로 갈지 DataGuide로 보완할지 결정)
2. `py -3 code/01_collect.py` — 2004-12-30 KOSPI 시총 상위 200개 보통주 일봉 → `PAPERS/data/daily/ohlcv/`
3. `py -3 code/02_pilot.py` — 학습 2005-01~2010-11, 평가 2011-01~2012-11. CPU로 1~2시간 예상

점검용: `py -3 code/smoke_test.py` (가짜 데이터, 약 45초)

| 파일 | 역할 |

| `code/charts.py` | JKX 규격 20일 이미지(64×60) 생성, 자체 점검 포함 |

| `results/sample_samsung_20d.png` | 삼성전자 20일 이미지 샘플 3장 |

## 데이터 경로 (2026-10-05 저녁 확정)

- **KOSPI 가격은 볼트에 이미 있는 DataGuide 일별 원본을 쓴다**(`data/원본_데이터/0_data/`, 상장+상폐 1,320종목, 2000-01-04~2026-04). `code/dg.py`가 엑셀을 `data/daily/dg/*.parquet`로 바꾸고, `dg.frames()`가 수정 OHLCV를 만든다(수정 비율 = 수정주가/종가, 거래정지일은 NaN).
- 검증: pykrx로 받았던 200종목과 일간 수익률을 대조하면 중앙값 차이가 0.0035%다. 예외 2종목(004550, 014900)은 거래정지 중 감자·분할을 DataGuide 수정주가가 보정하지 않았다.
- 추가로 필요한 것(투자자별 순매수, KOSDAQ)은 [[PAPERS/26-2/03_차트CNN_연구/DataGuide_다운로드_요청|DataGuide_다운로드_요청]]에 정리했다. 사람이 직접 받는다.
- 실행: `py -3 code/03_pilot_dg.py [스레드]` — KOSPI 전 보통주(2004-06~2012-12에 거래가 있는 853종목) 파일럿. CNN, 단순 지표, 상관을 한 번에 본다.
- 병렬 탐색 결과: A2 `results/a2_memo.md`(H1 파일럿, 잠정 '반전 없음'), A3 `results/a3_memo.md`(단순 지표 > CNN), A4 `results/a4_memo.md`(매일 이미지로 데이터 5배 → 검증 손실 0.698).

## 확인한 사실 (2026-10-05)

- pykrx 1.2.9는 KRX 로그인 없이 일별 OHLCV조차 빈 값을 돌려준다.
- **⚠️ 3단계 판정 정정 (2026-10-05 17:14):** pykrx 병렬 수집 중에 KRX가 이 PC의 IP를 1일간 차단했다. 사유는 이용약관 제10조 제2호(자동화 수단을 이용한 무단 수집 금지)다. 그래서 **논문용 데이터는 DataGuide(학교 라이선스)나 KRX Open API로 다시 받는다.** 지금 있는 `data/daily/ohlcv`(200종목)와 `investor`(50종목)는 탐색용으로만 쓴다.
- (정정 전 기록) 3단계 판정(⛳ 3-6): pykrx로 진행한다. 로그인하면 이렇다.
  - 수정주가(`adjusted=True`)는 2014-07 이전이 비어 있다. 비수정 가격·거래대금·등락률은 2005년치도 나온다. → `krx.ohlcv`가 등락률(기준가 대비)로 직접 수정한다. 네이버 수정주가와 대조하면 4종목(삼성전자·아모레퍼시픽·SK하이닉스·NAVER, 2014-08~2020-12) 모두 최대 상대오차 0.008% 이하이고, 분할 전 거래량도 보정된다.
  - 투자자별 거래대금(개인·외국인·기관 세부 12개 열)은 2000년부터 있다.
  - 상장폐지 종목도 상폐일까지 나온다(예: 005760 위너스인프라인, 2009-02-18까지).
  - KOSPI200 구성 종목은 2014-05-01 이전 자료가 없다. 그래서 파일럿 표본은 2004-12-30 시가총액 상위 200개 보통주로 대신한다(`data/daily/universe_pilot_20041230.txt`).
- 네이버 일봉은 수정주가이고 최대 3,000거래일(2014-07~)까지만 나온다. 거래정지일은 시가·고가·저가가 0이다.
- **네이버 거래량은 액면분할이 반영되지 않는다.** 삼성전자 2018-05 분할 전후로 거래량이 약 50배 뛴다. KRX 데이터도 3-4단계에서 확인해야 한다. 반영되지 않았다면 거래량 막대에 거래대금을 쓰거나 분할 비율로 보정한다.
- 이 노트북 CPU 기준으로 이미지 5천 장 1에폭에 약 45초 걸린다.

## 파일럿 설계 결정

- 표본은 2004-12-30 시점 시총 상위 200개 보통주로 고정했다. 현재 구성 종목을 쓰면 살아남은 종목만 고르는 편향이 생긴다.
- 계획의 시험 구간(2015~)은 쓰지 않는다. 파일럿 평가는 학습 구간 안쪽(2011~2012)에서 하고, 2010년 12월을 엠바고로 비운다.
- 알려진 한계: 5거래일 안에 상장폐지되는 종목은 라벨이 없어 빠진다. 이미지는 매주 만든다(JBK는 매일).
