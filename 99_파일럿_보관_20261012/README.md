- 이동한 것: `results/` 안의 a2·a3·a4·b01·r01·r02·v01·v02·dg_pilot·pilot_lr·collect·kaggle·sample 계열 파일과 폴더
- 남긴 것(`results/`): 패널 감사(q01), 패널 v2(p02), 변수 패널(f00·f01·f02), 데이터 접근 점검(step3)
- 코드: 2026-10-12 사용자 결정("백테스터는 없애고 아직 아무것도 분석 안 한 걸로")으로 분석·백테스터 스크립트 13개(`code/` 안의 b01·b02·v01·v02·r01·r02·a2_event·a3·a4·02_pilot·03_pilot_dg)를 `99_파일럿_보관_20261012/code/`로 옮겼다. 자료 수집·패널·변수·CNN 모델·이미지 코드는 `code/`에 그대로 있다. 되돌리려면 `_이동목록.csv`대로 옮긴다. 백테스터는 사전 고정한 명세로 새로 작성한다.
- 기획안 v2와 슬라이드가 이 결과의 수치를 인용한 곳이 있다. 데이터 확보 뒤 재실행 결과로 교체한다.
